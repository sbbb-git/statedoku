What state is NH?

NH is New Hampshire. It is the two-letter USPS postal code for New Hampshire, capital Concord, largest city Manchester.

Why the code is NH

NH is not the first two letters of anything. It is one letter per word: N for New, H for Hampshire. That rule holds for all ten state names built from two words, with no exceptions to memorise. New Hampshire NH, New Jersey NJ, New Mexico NM, New York NY, North Carolina NC, North Dakota ND, South Carolina SC, South Dakota SD, Rhode Island RI, West Virginia WV. If a state name has a space in it, take the initials and stop thinking.

The H points at an English county. Captain John Mason named his 1629 grant after Hampshire, the county in southern England where he had lived, so the second letter of the postal code is really the first letter of a place three thousand miles away.

Eight codes begin with N, and that block is the one place where the 1963 list needed repair. Publication 59, issued that October alongside the ZIP Code rollout, assigned NB to Nebraska. It was changed to NE in 1969 because NB collided with New Brunswick in Canadian use, which is also why Nevada sits on NV, pulled from the middle of its own name rather than the front. New Hampshire was never in that argument: no other state's two words begin with N and H, so NH was safe from the first draft. Before 1963 the written form was N.H.

Codes people confuse with NH

CodeStateWhy the mix-up happens
NJNew JerseySame New, same N. One letter separates a New England state of well under two million from the densest state in the country.
NMNew MexicoAlso New plus an initial, and a hand-printed H with a sloping crossbar reads as an M on an envelope. Opposite corners of the map result.
NVNevadaNevada is one word, so its code breaks the initials rule that NH follows. People applying the wrong rule to the wrong state land somewhere random in the N block.
NENebraskaNE looks like it should be shorthand for New England, the region NH actually sits in. It is Nebraska, and it only became NE in 1969.
VTVermontNot a letter problem, a shape problem. Vermont and New Hampshire are near mirror images sharing a border, so people who recognise the outline still pick the wrong code.

Quick facts about New Hampshire

  • Capital: Concord
  • Largest city: Manchester
  • Region: Northeast, specifically New England
  • Statehood: 21 June 1788, the 9th state, and its ratification was the one that put the Constitution into effect
  • Population band: 1 to 5 million
  • Area rank: 46th of 50

Where you will see NH

  • Mail. Concord, NH and Manchester, NH close the address line, with the ZIP Code following the two letters.
  • License plates. New Hampshire plates carry the state motto, Live Free or Die, above the numbers. The name is spelled out, not coded.
  • Election night. New Hampshire holds the first presidential primary in the country, so results boards and delegate tables label it NH for weeks before most other states appear at all.
  • Tax and shipping tables. New Hampshire has no statewide general sales tax, so ecommerce rate tables list NH as a zero row, next to Delaware, Montana, Oregon and Alaska.
  • Data files. FIPS code 33 and ISO 3166-2 code US-NH.
  • Chemistry, confusingly. The same two letters open NH3, the formula for ammonia, which is why a bare search for NH drifts away from geography.
