Stop inlining the 218 KB US map on 21 play pages

Ahrefs reported 21 slow pages, up 21 from the previous crawl. Exactly 21 pages
carry an inlined copy of the US states map, which is 218 KB of path data and
about 90% of each page's 243 KB. That match is what identified the cause.

/data/us-map.svg already existed and is byte-identical to the inlined copies,
right down to the root tag's class, role, aria-label and every data-* attribute
on the 50 paths. So the map was being shipped twice: once as a cacheable file
nothing used, and once inline on every page, where the browser has to download
it again on every navigation and can never reuse it.

The pages now fetch it. First play page pays the 218 KB once; every other one
reads it from cache. Verified in the browser: transferSize 0, one request per
page, served in a millisecond.

  21 pages, ~5,103 KB of HTML -> 519 KB, 90% less

Two shapes had to be handled. Eighteen pages inline an <svg> the game binds to
synchronously with document.querySelector('#pts-map-wrap svg'), so the body of
the game IIFE moves into a boot function that runs once the SVG is injected.
The three state-silhouettes pages instead carry a PATHS object holding the same
50 path strings; those are now derived from the fetched SVG. All 50 d values
were confirmed byte-identical to the file first, so the derivation is exact
rather than approximate. Both paths show a readable message if the fetch fails
instead of leaving a dead map.

No indexable text is lost: the map is role="img" with an aria-label, and the
state names live in data-name attributes, never in text nodes. Removing 218 KB
of markup also improves the text-to-HTML ratio considerably, which matters while
AdSense is judging the site.

Verified by playing them, not just by loading them:
  play/border-states       Texas counted correct 1/17, Florida wrong 1/5
  play/swing-states        Pennsylvania correct 0/7 -> 1/7
  fr/play/place-the-state  asked Maryland, clicked it, score 0 -> 1
  play/state-silhouettes   silhouette drawn, answered, score 0 -> 1, round 1 -> 2
  es/play/state-silhouettes  silhouette drawn, Spanish choices, SVG from cache

All 21 keep a single head and main, 63 JSON-LD blocks still parse, and the local
audit still reads zero on hreflang, orphans, broken links, meta descriptions and
Open Graph.
