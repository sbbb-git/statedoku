Stop the setup placeholder coming back as a 401

The setup instructions hand out `node bot/buffer-channels.mjs buf_TA_CLE_ICI`.
Run verbatim, the placeholder starts with `buf_` so it passed the format check,
reached Buffer, and came back "401 Unauthorized. The key is wrong, revoked, or
was copied with whitespace." None of which is true, and it points at the key
rather than at the paste.

The placeholder is now recognised before any request goes out and named as such.

The key can also come from stdin now, since passing it as an argument writes it
into shell history. Piping works, and with no argument on a terminal it prompts.
